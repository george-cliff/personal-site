# Icons

Icons are provided by [Tabler Icons](https://tabler.io/icons) (MIT licence), installed as `@iconify-json/tabler` and rendered with `astro-icon`, e.g. `<Icon name="tabler:mail" />`.

This folder is where `astro-icon` looks for custom local icons. Add an SVG here (e.g. `logo.svg`) to use it as `<Icon name="logo" />`.
